# AgBioTech Briefings

Daily interactive briefings on plant sciences, biotechnology and agriculture, compiled by a scheduled Claude routine.

- `briefings/briefing_YYYY_MM_DD.html`: one self-contained page per day (tabbed: Plant Sciences, Biotechnology, Agriculture).
- `index.html`: archive of all briefings, rebuilt with `python3 scripts/build_index.py`.
- Served with GitHub Pages from the `main` branch root.
